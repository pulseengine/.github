# .github

Organization-wide defaults for [PulseEngine](https://pulseengine.eu):

- `profile/README.md`: the profile shown on [github.com/pulseengine](https://github.com/pulseengine)
- `SECURITY.md`: the default security policy for every repo without its own

Labels, branch rules and other repo settings are not kept here; [temper](https://github.com/pulseengine/temper) syncs them from its `config.yml`.
